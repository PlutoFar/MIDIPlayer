================================================================================
                        MIDI Player 1.2 - 使用说明
================================================================================

【快速开始】

  1. 安装 VST3 乐器插件
     将 .vst3 文件复制到本程序的 VST3 文件夹，或系统标准目录：
     C:\Program Files\Common Files\VST3\

  2. 启动程序
     双击 MidiPlayer.exe。MidiWorker.exe 必须与主程序位于同一目录。

  3. 扫描插件
     点击界面上的 [扫描插件] 按钮

  4. 选择乐器
     从下拉菜单中选择一个 VST3 乐器

  5. 播放 MIDI
     将 .mid 或 .midi 文件拖入程序窗口


================================================================================
【快捷键】
================================================================================

  空格键        播放 / 暂停
  左方向键      上一曲
  右方向键      下一曲
  Delete        删除选中的曲目


================================================================================
【常见问题解答】
================================================================================

问：启动时提示"找不到 VCRUNTIME140.dll"或其他 DLL 错误？
答：这是缺少 Visual C++ 运行库。请下载安装：

    Microsoft Visual C++ 2015-2022 Redistributable (x64)
    下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe

    文件名：vc_redist.x64.exe
    安装后重新启动程序。

--------------------------------------------------------------------------------

问：点击"扫描插件"后列表里没有插件？
答：请检查以下几点：
    1. 确认插件是 64 位（x64）版本，32 位插件不兼容
    2. 确认插件文件扩展名是 .vst3
    3. 将插件放入以下任意位置：
       - 本程序目录下的 VST3 文件夹
       - C:\Program Files\Common Files\VST3\
    4. 某些插件需要额外的授权或激活才能被识别

--------------------------------------------------------------------------------

问：选择插件后没有声音？
答：请检查以下几点：
    1. 点击 [音频设置]，确认输出设备选择正确
    2. 检查系统音量和程序音量是否静音
    3. 确认插件已正确加载（可尝试打开插件界面查看）
    4. 某些插件需要先加载音色库才能发声

--------------------------------------------------------------------------------

问：播放时延迟很高，音符反应慢？
答：延迟主要取决于音频缓冲区大小：
    1. 点击 [音频设置]
    2. 降低"缓冲区大小"（Buffer Size），推荐 256 或 512
    3. 如果有 ASIO 驱动，优先选择 ASIO（延迟最低）
    4. 注意：缓冲区太小可能导致爆音，需要平衡

--------------------------------------------------------------------------------

问：插件进程停止后如何恢复？
答：记录提示中的错误信息，再重新选择插件。
    如问题重复出现，将 portable.dat 改名为 portable_debug.dat，
    重启程序并复现问题，在问题反馈中附上 debug_log.txt。

--------------------------------------------------------------------------------

问：程序完全无响应，连音乐都停了？
答：使用任务管理器结束 MidiPlayer.exe，再重新启动。
    保留 MIDI 文件、插件名称和复现步骤，提交问题反馈。
    重置设置前应备份 Settings 文件夹。

--------------------------------------------------------------------------------

问：某些 MIDI 文件播放出现断音或卡顿？
答：这通常与 MIDI 文件复杂度或插件性能有关：
    1. 尝试增大缓冲区大小
    2. 关闭其他占用 CPU 的程序
    3. 某些大型音源（如管弦乐）需要较多 CPU 资源
    4. 检查 MIDI 文件是否损坏

--------------------------------------------------------------------------------

问：插件界面显示异常或打不开？
答：插件界面由插件本身提供：
    1. 确认插件版本是最新的
    2. 某些插件与高 DPI 显示器兼容性不好
    3. 尝试在 Windows 设置中调整缩放比例
    4. 联系插件开发商获取支持

--------------------------------------------------------------------------------

问：如何保存播放列表？
答：点击播放列表区域的 [保存] 按钮，选择保存位置。
    点击 [加载] 按钮可以加载之前保存的播放列表。
    文件格式为 JSON，可在不同电脑间传输。

    注意：如果您加载过播放列表文件，下次启动程序时会自动恢复。
    临时拖入的 MIDI 文件不会被自动记忆。

--------------------------------------------------------------------------------

问：便携版如何使用？
答：本程序支持便携模式：
    - 发布包包含 portable.dat，设置保存在程序目录下的 Settings 文件夹
    - 可以整个文件夹复制到 U 盘随身携带
    - 升级前退出程序，保留 Settings 和 VST3 文件夹，再解压新版本
    - 播放列表引用的 MIDI 文件和插件音色库需要随使用环境配置

问：提示设置未保存时如何处理？
答：确认程序目录可写、磁盘空间充足，并关闭占用配置文件的程序。
    当前设置在本次运行中仍然生效。退出时可取消操作，处理文件问题后重新退出。

================================================================================
【系统要求】
================================================================================

  操作系统：Windows 10 1809 或更高版本
  处理器：  x64 架构（不支持 32 位系统）
  内存：    4GB 以上（大型音源建议 8GB+）
  声卡：    支持 WASAPI 或 ASIO
